# Queridinha da Praia

Projeto final da disciplina de Desenvolvimento Front-End para Web, do curso de Ciência da Computação.

O projeto consiste em um site de loja virtual para a Queridinha da Praia, especializada em roupas femininas e acessórios.

# Tecnologias utilizadas

- HTML
- CSS

# Funcionalidades

- Catálogo de roupas e acessórios
- Formulários de login e cadastro
- Sacola de compras com opções de pagamento e entrega
- Painel administrativo demonstrativo
- Layout responsivo

# Como executar

Baixe os arquivos do projeto e abra o `index.html` em um navegador.
